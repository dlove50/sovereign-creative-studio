# Image template gallery: behavioural reference (observed 2026-10-21)

Observed by using davinci.ai/app/image/templates as a signed-in user (David's account), opening
each template and its option menus. No code, artwork or prompt text was copied; this records only
each template's inputs and choices so Sovereign's own gallery behaves the same way.

Flow: category tabs (All, Trending, Edit, Product/Ads, Photography, Creative, Tattoo) -> card ->
panel with title, one-line description, example, required fields (*) -> Generate (credit cost).
Engines behind it are cloud models (Nano Banana 2 / Seedance / Kling / Runway); Sovereign uses local
Qwen Image Edit 2509 (multi-reference edit), Flux and the AI Enhance pipeline instead.
