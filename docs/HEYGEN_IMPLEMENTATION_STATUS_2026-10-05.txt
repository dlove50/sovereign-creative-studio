SOVEREIGN / HEYGEN FEATURE REVIEW — 5 OCTOBER 2026

Objective
Implement equivalent HeyGen workflows inside Sovereign, with local models where practical and explicit provider connectors where required. A feature button, source file, or passing mock test is not proof of full product parity. HeyGen's proprietary models and training assets have not been transferred.

New completed source work in this pass

1. PDF slide visuals
PDF pages are rendered locally with PDFium, retained as private movie assets, and composited beside the presenter (or above it in portrait). Blank/scanned pages keep their images and warn that narration must be added. Each asset request verifies movie ownership. Maximum 30 pages, 50 MB upload. PPTX remains text import; export a deck to PDF to preserve visuals. FFmpeg composition tests verify both orientations, audio, duration, and complete decode.

2. Batch variants
Each CSV/manual row can override the default presenter and voice. Optional CSV headers: avatar_id and tts_voice_id. Existing script-only files still work, including quoted multiline scripts. All presenters are validated before any batch movie is created; one invalid/foreign presenter rejects the whole batch. This is row-based variation, not HeyGen's script-by-avatar cross-product UI.

3. SCORM 1.2 export
Saved interactive lessons export a self-contained ZIP with manifest, player, quiz data, and deduplicated owned video files. The player supports branching, feedback, first-attempt scoring, LMS resume, explicit completion, and session shutdown. No runtime studio server or network calls are required. Media limit: 512 MB. Empty steps and graphs without a reachable final step are rejected. Preview without an LMS is explicitly labelled; actual target-LMS import is not yet tested. SCORM 2004/xAPI and automatic LMS synchronization are not implemented.

4. Prompt-generated presentations
The installed local Qwen model drafts 2–10 slides with titles, bullets, and narration. Original static slide images and editable narration are saved as a movie draft; no automatic video render or credit charge. Output length/schema failures are reported, not silently accepted. The actual qwen3.8:27b model produced two slides in 25.73 seconds, with images visually reviewed. English typography was tested; full multilingual font coverage and editable slide objects remain gaps.

How to use the new workflows after activation
- Slides: Import a PDF, choose presenter/voice, review warnings, add narration to blank pages, then render from the movie editor.
- Presentations: Slides > Create from a prompt, enter brief, select 2–10 slides and presenter, Create scenes, then Review scenes. Validate generated facts before rendering.
- Batch: Import CSV with script and optional title, avatar_id, tts_voice_id; or set Presenter/Voice for individual rows. Draft first to review variation before rendering.
- Training: Save a lesson whose final step has no choices. Select Export SCORM 1.2. Import the ZIP directly into an LMS as SCORM 1.2; do not upload the extracted folder. Confirm resume, score, media playback and completion in that LMS before publishing it to learners.
